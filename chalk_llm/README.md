# Welcome to Chalk ■

This project was set up with `chalk init`.

- `chalk.yaml` names the Chalk project and its environments.
- `pyproject.toml` holds the Python dependencies, managed with [uv](https://docs.astral.sh/uv/).
- `CLAUDE.md` or `AGENTS.md` gives coding agents Chalk-specific instructions.

Docs: https://docs.chalk.ai
